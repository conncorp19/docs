클래스폼은 신청 페이지 생성부터 신청 관리, 신청자 관리까지 교육·모집 운영에 필요한 기능을 제공합니다.

---

## 운영자 기능

### **대시보드**

<Frame caption="대시보드">
  ![M Feature Dashboard 1](/images/m_feature_dashboard-1.png)
</Frame>

매출, 신청 현황, 처리가 필요한 건수를 한눈에 파악할 수 있습니다. 기간별로 조회하고, 처리가 필요한 건은 바로 해당 관리 화면으로 이동할 수 있습니다.

- **수익 현황** — 총 수익, 입금액, 환불액을 확인합니다.
- **신청 현황** — 총 신청, 확정, 취소 건수를 확인합니다.
- **처리 필요** — 입금확인요청, 환불요청, 확정대기, 기한만료 건을 바로 확인합니다.

### 신청 페이지 자동 생성

<Frame caption="센터 신청 페이지 예시">
  ![M Feature Student](/images/m_feature_student.png)
</Frame>

{/* 📸 스크린샷: 신청자가 보는 센터 홈페이지 (센터 로고, 카테고리, 클래스 목록이 표시된 상태)
- 파일명: features-center-page.png
- 권장 크기: 1200x900px
- 포함 요소: 센터 로고/이름, 카테고리 탭, 클래스 카드 목록(이미지, 클래스명, 담당자/강사, 비용, 정원 표시)
*/}

센터 정보와 클래스를 등록하면 신청 페이지가 자동으로 만들어집니다. 각 센터마다 `classform.net/center/센터이름` 형태의 고유 URL이 부여되어 SNS, 메신저, 블로그 어디든 간편하게 공유할 수 있습니다.

클래스 상세 페이지에는 리치 텍스트 설명, 이미지, 담당자/강사 프로필, 커리큘럼이 표시됩니다. 신청자는 별도 앱 설치 없이 링크를 클릭하면 바로 접속할 수 있습니다.

### 클래스 등록/관리

<Frame caption="클래스 관리 목록 화면">
  ![M Quickstart Create Class 1](/images/m_quickstart-create-class-1.png)
</Frame>

{/* 📸 스크린샷: 클래스 관리 목록 페이지
- 파일명: features-class-list.png
- 권장 크기: 1200x800px
- 포함 요소: 상단 현황 요약(전체/오픈예정/모집중/대기접수/모집마감), 클래스 목록 테이블, 필터/검색 영역
*/}

수업·행사·모임·모집 중 템플릿을 선택하면 라벨과 입력 항목이 자동으로 맞춰집니다. 클래스명, 일정, 비용, 정원, 담당자/강사 정보까지 운영에 필요한 항목이 모두 준비되어 있습니다.

- 카테고리별로 클래스를 분류하고, 카테고리 공개/비공개를 설정할 수 있습니다.
- 클래스별로 신청자에게 받고 싶은 추가 질문(커스텀 질문)을 설정할 수 있습니다.
- 클래스 이미지, 태그, 커리큘럼, 취소/환불 규정을 개별 설정할 수 있습니다.
- 클래스별로 가격 표시 여부를 끌 수 있어, 무료 프로그램이나 비공개 가격 운영에 적합합니다.

### 신청 상태 관리

<Frame caption="신청 관리 화면">
  ![M Feature Apply](/images/m_feature_apply.png)
</Frame>

{/* 📸 스크린샷: 신청 관리 목록 페이지
- 파일명: features-enrollment.png
- 권장 크기: 1200x800px
- 포함 요소: 상단 수익/신청 현황 카드, 상태별 탭(입금대기/입금확인요청/확정대기 등), 신청 목록 테이블
*/}

입금대기, 입금확인, 확정, 환불까지 11개 탭으로 나눠서 한눈에 확인하고, 클릭 한 번으로 처리할 수 있습니다.

- **입금확인** — 신청자의 입금을 확인하고 개별 또는 일괄로 승인할 수 있습니다.
- **기한만료 관리** — 입금 기한이 지난 건은 별도 표시되며, 일괄 취소하거나 사정을 고려해 입금확인 처리할 수 있습니다.
- **환불 관리** — 전체 환불, 부분 환불, 환불 거절을 지원합니다.
- **신청현황 다운로드** — 현재 조회 중인 신청 내역을 파일로 내려받을 수 있습니다.

---

### 정원/대기 자동 관리

<Frame caption="클래스 상세 — 정원 및 대기 현황">
  ![M Feature Wait](/images/m_feature_wait.png)
</Frame>

{/* 📸 스크린샷: 클래스 상세 페이지의 정원/신청/확정/대기 현황 영역
- 파일명: features-capacity.png
- 권장 크기: 1200x600px
- 포함 요소: 정원 n/n, 신청 n건, 확정 n명, 대기 n명 표시, 신청자 현황 테이블
*/}

정원이 차면 자동으로 마감되고, 대기 신청으로 전환됩니다. 빈자리가 나면 대기자를 정규로 배정할 수 있습니다.

- 클래스별로 최소/최대 모집 인원과 대기 최대 인원을 설정합니다.
- 대기 최대인원을 0으로 설정하면 대기 신청을 받지 않습니다.
- 모집 상태(오픈 예정, 모집중, 대기 접수, 모집 마감)는 신청 기간과 정원에 따라 자동 계산됩니다.

---

### 담당자/강사 관리

<Frame caption="담당자/강사 관리 화면">
  ![M Feature Instructor](/images/m_feature_instructor.png)
</Frame>

{/* 📸 스크린샷: 담당자/강사 목록 페이지
- 파일명: features-instructor.png
- 권장 크기: 1200x600px
- 포함 요소: 담당자/강사 목록 테이블(이름, 연락처, 상태, 담당 클래스), 상단 현황(총 인원/활동중/비활동)
*/}

담당자/강사를 등록하고 클래스에 배정할 수 있습니다. 프로필(소개글, 사진)은 신청 페이지에서 신청자에게 표시됩니다.

- 담당자/강사별 담당 클래스 내역을 확인할 수 있습니다.
- 관리자 전용 비공개 메모(급여 정보, 근무 특이사항 등)를 남길 수 있습니다.
- 담당자/강사에게 SMS를 발송하거나 목록을 파일로 내려받을 수 있습니다.
- 토큰\+PIN 공유 링크로 별도 계정 없이 본인 담당 클래스의 신청 현황을 직접 조회하도록 할 수 있습니다.

### SMS 알림

<Frame caption="SMS 발송 설정 화면">
  ![M Feature Sms](/images/m_feature_sms.png)
</Frame>

{/* 📸 스크린샷: 센터 설정 > SMS 발송 설정 영역
- 파일명: features-sms.png
- 권장 크기: 1200x600px
- 포함 요소: 신청완료 안내(LMS), 확정 안내(SMS), 입금만료 안내(SMS) 각각의 사용/미사용 토글
*/}

신청 완료, 입금 확인이 자동으로 발송됩니다. **자동 알림은 Basic, Pro 플랜에서 무료 무제한**으로 제공되어, 신청자가 직접 확인하지 않아도 중요한 안내를 놓치지 않습니다. (Free 플랜에서는 사용할 수 없습니다.)

| 알림 종류 | 발송 시점 | 유형 |
| --- | --- | --- |
| 신청완료 안내 | 신청 완료 시 | 알림톡/SMS |
| 확정 안내 | 입금 확인 후 | 알림톡/SMS |

각 항목별로 발송 여부를 개별 설정할 수 있으며, 신청자·담당자/강사에게 직접 문자를 보내는 **수동 SMS 발송**도 가능합니다. 수동 SMS는 플랜별 월간 한도가 적용됩니다.

<Note>
  기본적으로 알림톡이 발송되며, 카카오톡을 설치하지 않은 신청자에게는 SMS가 발송됩니다.
</Note>

<Frame caption="팀원 관리 화면">
  ![M Feature Team](/images/m_feature_team.png)
</Frame>

{/* 📸 스크린샷: 팀원 관리 목록 페이지
- 파일명: features-team.png

<Note>
  팀원 관리는 Pro 플랜 이상에서 사용할 수 있습니다.
</Note>

## 신청자 기능

  ![M Feature S Class](/images/m_feature_s_class.png)
</Frame>

{/* 📸 스크린샷: 신청자가 보는 클래스 상세 페이지

### 장바구니

<Frame caption="장바구니 화면 (신청자 화면)">
  ![M Feature S Basket](/images/m_feature_s_basket.png)
</Frame>

{/* 📸 스크린샷: 신청자 장바구니 화면
- 파일명: features-student-cart.png
- 권장 크기: 800x900px (모바일 비율 권장)
- 포함 요소: 담긴 클래스 목록, 비용 합계, "신청하기" 버튼

여러 클래스를 담아 한 번에 신청할 수 있습니다. 클래스마다 따로 신청할 필요 없이 비용이 자동 계산됩니다.

### 간편 인증

<Frame caption="신청자 인증 화면">
  ![M Feature S Auth](/images/m_feature_s_auth.png)
</Frame>

{/* 📸 스크린샷: 신청자 로그인/인증 화면
- 파일명: features-student-auth.png
- 권장 크기: 800x600px (모바일 비율 권장)
- 포함 요소: 이름, 연락처, PIN 입력 필드
*/}

앱 설치 없이, 회원가입 없이 바로 신청할 수 있습니다. 이름, 연락처, 4자리 PIN이면 충분합니다. 본인이 아닌 가족이나 지인을 대신 신청할 수도 있습니다.

---

### SMS 알림 (신청자)

<Frame caption="SMS (알림톡)">
  ![M Feature S Sms](/images/m_feature_s_sms.png)
</Frame>

신청자에게도 중요한 알림(SMS 또는 알림톡)이 자동으로 발송됩니다. 신청 완료 시 입금 안내, 확정 안내, 입금 기한 임박 알림을 받을 수 있어 직접 확인하지 않아도 놓치지 않습니다.
