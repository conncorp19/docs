## 기본 정보

<Frame caption="센터 기본 정보">
  ![Mc Setting Info 1](/images/mc_setting_info-1.png)
</Frame>

{/* 📸 스크린샷: 센터 설정 > 기본 정보 섹션
- 파일명: settings-01.png
- 권장 크기: 1200x800px
- 포함 요소: 센터 주소(slug) 입력, 센터 로고 업로드, 센터 이름 입력, 센터 소개 입력
*/}

**센터 설정**에서 센터의 기본 정보를 확인하고 수정할 수 있습니다.

- **센터 주소** — 센터 고유 주소를 등록하면 신청자에게 공유할 수 있는 짧은 링크가 만들어집니다. 짧은 주소는 카카오톡, 인스타그램 등에 공유할 때 편리합니다.
- **센터 로고** — 권장 사이즈 512x512px, JPG/PNG 형식, 최대 1MB입니다.
- **센터 이름** — 필수 입력 항목입니다. 신청 페이지에 표시됩니다.
- **센터 소개** — 센터에 대한 간단한 소개를 입력할 수 있습니다.
- **전화번호(고객센터), 이메일** — 센터 연락처를 등록합니다. SMS, 알림톡에 노출됩니다. (SMS 발신 연락처로 등록되지 않습니다.)

<Warning>
  센터 URL 주소는 최초 등록 시에만 설정할 수 있으며, 이후 변경할 수 없습니다. 처음 등록할 때 신중하게 정해 주세요.
</Warning>

## 연락처 및 입금 정보

<Frame caption="입금 정보 설정">
  ![Mc Setting Contact](/images/mc_setting_contact.png)
</Frame>

{/* 📸 스크린샷: 센터 설정 > 연락처 및 입금 정보 섹션

- **입금 정보** — 유료 클래스의 경우 계좌정보를 입력해야 합니다.

<Note>
  기한이 지나도 자동으로 취소되지 않으며, 기한 만료 건은 별도 표시됩니다.
</Note>

## 운영 설정

<Frame caption="운영 설정">
  ![Mc Setting 03](/images/mc_setting_03.png)
</Frame>

{/* 📸 스크린샷: 센터 설정 > 운영 설정 섹션
- 파일명: settings-03.png
- 권장 크기: 1200x600px
- 포함 요소: 운영 여부 토글, 클래스 인원 현황 토글, 더보기 기능 토글, 문의 채널 설정(카카오톡/인스타그램/기타)
*/}

센터의 운영 상태와 신청 페이지 표시 옵션을 설정할 수 있습니다.

- **운영 여부** — 중지로 전환하면 신청자 홈이 비활성화됩니다. (접속 불가)
- **클래스 인원 현황** — 보이기로 설정하면 신청자에게 클래스 정원과 현재 신청 인원이 표시됩니다.
- **센터 클래스 목록 더보기 기능** — 사용으로 설정하면 신청자가 보는 센터 페이지의 카테고리별 목록에 클래스를 일부만 표시하도록 합니다.

## SMS 발송 설정

<Frame caption="SMS 발송 설정">
  ![Mc Setting 05](/images/mc_setting_05.png)
</Frame>

{/* 📸 스크린샷: 센터 설정 > SMS 발송 설정 섹션
- 파일명: settings-04.png
- 권장 크기: 1200x500px
- 포함 요소: 신청완료 안내(LMS) 토글, 확정 안내(SMS) 토글, 입금만료 안내(SMS) 토글
*/}

신청 및 결제 관련 SMS 자동 발송을 설정할 수 있습니다.

| 항목 | 발송 시점 | 유형 |
| --- | --- | --- |
| 신청완료 안내 | 신청 완료 시 | 알림톡 / SMS |
| 확정 안내 | 확정 시 | 알림톡 / SMS |

각 항목별로 사용/미사용을 개별 설정할 수 있습니다.

<Note>
  알림톡을 기본으로 발송하며, 신청자가 카카오톡을 설치하지 않았을 경우 SMS로 발송됩니다.

  플랜별 SMS 한도에 달했을 경우 발송되지 않습니다. (별도로 한도를 늘릴 수 없습니다.)
</Note>

## 활동 로그

<Frame caption="활동 로그">
  ![Mc Setting Log](/images/mc_setting_log.png)
</Frame>

{/* 📸 스크린샷: 활동 로그 화면
- 파일명: settings-05.png
- 권장 크기: 1200x700px
- 포함 요소: 활동 로그 테이블(시간, 수행자, 작업 종류, 상세 내용), 검색 필드, 작업 종류 필터
*/}

센터 설정 우측 상단의 **활동 로그**를 클릭하면, 최대 3개월까지의 활동 내역을 확인할 수 있습니다. 시간, 수행자, 작업 종류, 상세 내용이 기록됩니다.

수행자나 대상으로 검색하거나, 작업 종류별로 필터링할 수 있습니다.

<Info>
  활동 로그는 Pro 플랜 이상에서 사용할 수 있습니다.
</Info>

## SMS 발송 내역

<Frame caption="SMS 발송 내역">
  ![Mc Setting Smslog](/images/mc_setting_smslog.png)
</Frame>

{/* 📸 스크린샷: SMS 발송 내역 화면
- 파일명: settings-06.png
- 권장 크기: 1200x700px
- 포함 요소: SMS 발송 내역 테이블(시간, 유형, 메시지 종류, 결과, 건수, 수신번호, 발신내용), 검색 필드, 유형 필터
*/}

센터 설정 우측 상단의 **SMS 발송 내역**을 클릭하면, 최대 3개월까지의 SMS 발송 내역을 확인할 수 있습니다. 시간, 유형(신청/수동발송), 메시지 종류(알림톡/SMS), 결과(성공/실패), 건수, 수신번호, 발신내용이 표시됩니다.

발송자나 수신번호로 검색하거나, 유형별로 필터링할 수 있습니다.
