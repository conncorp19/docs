---
title: "빠른 시작"
description: "클래스폼으로 신청 페이지를 만들고 신청을 받기까지의 과정을 안내합니다."
icon: "rocket"
---

클래스폼은 구글폼과 엑셀로 처리하던 교육·모집 신청 업무를 하나로 통합하는 서비스입니다. 가입부터 신청을 받기까지, 5단계로 시작할 수 있습니다.

---

<Steps>
  <Step title="회원가입">
    <Frame caption="클래스폼 회원가입 화면">
      ![M Quickstart Signup](/images/m_quickstart-signup.png)
    </Frame>

    {/* 📸 스크린샷: classform.net 회원가입 페이지
- 파일명: quickstart-signup.png
- 권장 크기: 1200x800px
- 포함 요소: 이메일/이름/연락처/비밀번호 입력 필드, 약관 체크박스, "회원가입" 버튼, Google 로그인 버튼
*/}

    [classform.net](https://classform.net)에 접속하여 \[무료로 시작하기\]를 클릭합니다. 이메일, 이름, 연락처, 비밀번호를 입력하고 약관에 동의하면 가입이 완료됩니다.

    가입 후 이메일로 발송되는 인증 메일에서 \[이메일 인증하기\]를 클릭해 주세요.

    <Tip>
      Google 계정으로 가입하면 별도 인증 없이 바로 시작할 수 있습니다.
    </Tip>

    <br />
  </Step>
  <Step title="센터 만들기">
    <Frame caption="센터 생성 화면">
      ![M Quickstart Create Center](/images/m_quickstart-create-center.png)
    </Frame>

    {/* 📸 스크린샷: 센터 생성 플로우 (요금제 선택 → 센터 이름 입력 → 생성 확인)
- 파일명: quickstart-create-center.png
- 권장 크기: 1200x700px
- 포함 요소: 요금제 선택 카드(Free/Basic/Pro), 센터 이름 입력 필드, "센터 생성" 버튼
*/}

    로그인 후 \[센터 만들기\]를 클릭합니다. 플랜을 선택하고 센터 이름을 입력하면 센터가 생성됩니다.

    먼저 Free 플랜으로 시작하고, 필요할 때 업그레이드할 수 있습니다.

    <Frame caption="센터 설정">
      ![M Quickstart Center Setting 3](/images/m_quickstart-center-setting-3.png)
    </Frame>

    {/* 📸 스크린샷: 센터 생성 플로우 (요금제 선택 → 센터 이름 입력 → 생성 확인)
- 파일명: quickstart-create-center.png
- 권장 크기: 1200x700px
- 포함 요소: 요금제 선택 카드(Free/Basic/Pro), 센터 이름 입력 필드, "센터 생성" 버튼
*/}

    센터가 만들어지면 **센터 설정**에서 입금 계좌, 연락처 등 기본 정보를 입력해 주세요.

    입금 계좌는 신청자에게 안내되는 정보이므로 정확하게 입력해야 합니다.

    <br />
  </Step>
  <Step title="담당자/강사 등록">
    <Frame caption="담당자/강사 등록 화면">
      ![M Quickstart Instructor](/images/m_quickstart-instructor.png)
    </Frame>

    {/* 📸 스크린샷: 담당자/강사 등록 폼
- 파일명: quickstart-instructor.png
- 권장 크기: 1200x700px
- 포함 요소: 이름, 연락처, 프로필(소개) 입력 필드, 프로필 사진 업로드 영역
*/}

    담당자/강사 관리 → \[담당자/강사 등록\]에서 새 담당자/강사를 등록합니다. 이름, 연락처, 소개를 입력하면 됩니다.

    프로필은 신청 페이지의 클래스 정보에 표시됩니다.

    <Note>
      담당자/강사 없이도 클래스를 만들 수 있습니다. 나중에 등록해도 괜찮습니다.
    </Note>

    <br />
  </Step>
  <Step title="클래스 만들기">
    <Frame caption="클래스 등록 화면">
      ![M Quickstart Create Class](/images/m_quickstart-create-class.png)
    </Frame>

    {/* 📸 스크린샷: 클래스 만들기 폼 (기본 정보 섹션)
- 파일명: quickstart-create-class.png
- 권장 크기: 1200x800px
- 포함 요소: 템플릿 선택, 클래스명, 카테고리, 담당자/강사 선택, 비용, 정원 입력 필드
*/}

    클래스 관리 → \[클래스 만들기\]에서 새 클래스를 등록합니다.

    | 필수 항목 | 선택 항목 |
    | --- | --- |
    | 클래스명 | **템플릿 (수업/행사·모임/모집)**, 카테고리, 담당자/강사, 장소 |
    |  | 신청 기간, 진행 기간 |
    |  | 비용, 정원, 대기 인원 |
    |  | 클래스 소개, 커리큘럼 |

    가장 먼저 템플릿(수업/행사·모임/모집)을 선택하면 라벨과 입력 항목이 자동으로 맞춰집니다. 클래스를 공개로 설정하면 **센터 클래스 홈**에 바로 표시됩니다.

    <br />
  </Step>
  <Step title="센터 클래스 홈">
    <Frame caption="센터 클래스 홈">
      ![M Quickstart Home](/images/m_quickstart-home.png)
    </Frame>

    {/* 📸 스크린샷: 센터 설정의 센터 주소(slug) 영역 또는 센터 페이지 미리보기
- 파일명: quickstart-share.png
- 권장 크기: 1200x600px
- 포함 요소: classform.net/센터이름 형태의 URL, 복사 버튼 또는 공유 안내
*/}

    사이드바 하단의 \[센터 클래스 홈\]을 클릭하면 신청 사이트를 확인할 수 있습니다.

    카카오톡, 인스타그램, 블로그, 이메일 등 어디든 센터 클래스 홈 주소를 공유해주세요. 신청자는 회원가입 없이 바로 신청할 수 있습니다.

    <Tip>
      센터 설정에서 짧은 주소(slug)를 등록하면 간결한 링크를 사용할 수 있습니다.
    </Tip>
  </Step>
</Steps>
