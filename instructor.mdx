</Frame>

{/* 📸 스크린샷: 담당자/강사 관리 목록 페이지

*/}

**담당자/강사 관리**에서 센터에 등록된 전체 담당자/강사 목록을 확인할 수 있습니다. 상단에 총 인원, 활동중, 비활동 현황이 표시됩니다.

이름이나 연락처로 검색하거나, 상태별로 필터링할 수 있습니다.

- **SMS 보내기** — 선택한 담당자/강사에게 문자를 발송합니다.
- **다운로드** — 목록을 파일로 내려받습니다.

<Note>
  클래스 템플릿에 따라 라벨이 달라집니다. **수업** 템플릿에서는 "강사", **행사·모임** 또는 **모집** 템플릿에서는 "담당자"로 표시됩니다.
</Note>

## 담당자/강사 상세

<Frame caption="담당자/강사 상세">
  ![Mc Ins View](/images/mc_ins_view.png)
</Frame>

{/* 📸 스크린샷: 담당자/강사 상세 페이지
- 파일명: instructor-02.png
- 권장 크기: 1200x800px
- 포함 요소: 기본정보(이름, 연락처, 이메일, 계좌정보), 프로필(소개), 관리자 메모 영역, 담당 클래스 내역 테이블
*/}

목록에서 담당자/강사를 선택하면 상세 화면으로 이동합니다. 기본정보(이름, 연락처, 이메일, 계좌정보)와 프로필(소개)을 확인할 수 있습니다.

- **관리자 메모 (비공개)** — 급여 정보, 근무 특이사항 등 관리자만 볼 수 있는 메모를 남길 수 있습니다. 이 메모는 담당자/강사와 신청자에게 보이지 않습니다.
- **담당 클래스 내역** — 해당 담당자/강사가 맡고 있는 클래스 목록이 표시됩니다.

## 담당자/강사 등록

{/* 📸 스크린샷: 담당자/강사 등록 폼
- 파일명: instructor-03.png
- 권장 크기: 1200x900px
- 포함 요소: 프로필 사진 업로드, 이름/상태/연락처/이메일 입력, 프로필(소개) 텍스트 영역, 관리자 메모 영역, 계좌 정보(은행/계좌번호/예금주)
*/}

담당자/강사 관리 우측 상단의 **담당자/강사 등록**을 클릭하면 새로운 담당자/강사를 등록할 수 있습니다.

| 항목 | 설명 | 필수 |
| --- | --- | :-: |
| 이름 | 담당자/강사 이름 | ✓ |
| 상태 | 활동중 또는 비활동 |  |
| 연락처 / 이메일 | 담당자/강사의 연락 정보 |  |
| 프로필 (소개) | 신청 페이지의 클래스 정보에 표시됩니다. |  |
| 관리자 메모 (비공개) | 급여 정보, 근무 특이사항 등을 기록합니다. |  |
| 계좌 정보 | 은행, 계좌번호, 예금주를 입력합니다. |  |

프로필 사진도 등록할 수 있으며, 신청 페이지에서 담당자/강사 정보와 함께 표시됩니다.

별도의 회원가입이나 로그인 없이, 담당자/강사가 본인이 담당하는 클래스의 신청 현황을 직접 조회하도록 할 수 있습니다.
