<Frame caption="수강생 목록">
  ![Mc Student List](/images/mc_student_list.png)
</Frame>

{/* 📸 스크린샷: 수강생 관리 목록 페이지

*/}

**수강생 관리**에서 센터에 등록된 전체 수강생 목록을 확인할 수 있습니다. 이름, 연락처, 신청 수, 확정 수, 가입일/최근접속 정보가 표시됩니다.

이름이나 연락처로 검색할 수 있습니다.

- **SMS 보내기** — 선택한 수강생에게 문자를 발송합니다.
- **수강생 다운로드** — 목록을 파일로 내려받습니다.

## 수강생 상세

<Frame caption="수강생 상세">
  ![Mc Student View](/images/mc_student_view.png)
</Frame>

{/* 📸 스크린샷: 수강생 상세 페이지
- 파일명: students-02.png
- 권장 크기: 1200x800px
- 포함 요소: 기본 정보(이름, 연락처, 가입일), 메모 입력 영역, 신청 내역 테이블(클래스명, 강사, 금액, 상태), "신청 상세" 링크, "클래스로 이동" 링크
*/}

수강생 목록에서 수강생을 선택하면 상세 화면으로 이동합니다. 기본 정보(이름, 연락처, 가입일)와 신청 내역을 확인할 수 있습니다.

- **메모** — 관리자 전용 메모를 남길 수 있습니다. 메모는 수강생에게 보이지 않습니다.
- **신청 내역** — 해당 수강생이 신청한 클래스 목록, 강사, 금액, 상태가 표시됩니다. **신청 상세**를 클릭하면 신청 관리의 상세 화면으로 이동하고, **클래스로 이동**을 클릭하면 해당 클래스 상세 화면으로 이동합니다.

<Frame caption="수강생 정보 수정">

*/}

수강생 상세에서 **정보 수정**을 클릭하면 이름, 연락처, 메모를 수정할 수 있습니다.

### PIN 번호 관리

수강생이 비밀번호를 분실한 경우, **PIN 초기화**를 클릭하면 PIN 번호가 `0000`으로 초기화됩니다.

초기화 후 수강생에게 새 PIN 설정을 안내해 주세요. 수강생은 로그인 후 설정에서 직접 PIN을 변경할 수 있습니다.

### 수강생 삭제

하단의 **삭제**를 클릭하면 수강생 정보를 삭제할 수 있습니다.

<Warning>
  삭제된 수강생 정보는 복구할 수 없습니다.
</Warning>
