## 수강생 로그인

<Frame caption="마이페이지 로그인">
  ![Ms Order Login 1](/images/ms_order_login-1.png)
</Frame>

센터 상단의 \[로그인\]을 클릭한 후, 이름과 연락처, PIN을 입력합니다.

#### PIN을 잊었을 때

PIN을 분실한 경우, 두 가지 방법으로 재설정할 수 있습니다.

| 방법 | 설명 |
| --- | --- |
| SMS 본인인증 | 마이페이지 로그인 화면에서 직접 재설정합니다. |
| 센터 문의 | 센터 관리자에게 문의하여 비밀번호 초기화를 요청합니다. |

## 마이페이지 접속

<Frame caption="마이페이지 로그인">
  ![Ms Order Mymenu](/images/ms_order_mymenu.png)
</Frame>

{/* 📸 스크린샷: 마이페이지 로그인 화면
- 파일명: my-status-01.png
- 권장 크기: 800x800px (모바일 비율 권장)
- 포함 요소: 이름, 연락처, 비밀번호(PIN) 입력 필드, "로그인" 버튼
*/}

센터 페이지 상단의 **내 신청 조회**를 클릭한 후, 이름·연락처·비밀번호를 입력하면 마이페이지에 접속할 수 있습니다.

비밀번호는 최초 수강신청 시 설정한 간편 비밀번호(4~6자리)입니다.

## 신청 내역 확인

<Frame caption="신청 내역">
  ![Ms Order My](/images/ms_order_my.png)
</Frame>

{/* 📸 스크린샷: 마이페이지 신청 내역 화면
- 파일명: my-status-02.png
- 권장 크기: 800x1000px (모바일 비율 권장)
- 포함 요소: 신청한 클래스 목록, 각 건의 결제 상태(입금대기/수강확정 등), 수강 상태
*/}

마이페이지에서 현재 신청한 클래스 목록과 각 건의 결제, 수강 상태를 확인할 수 있습니다.

- **입금 확인 요청** — 입금을 완료하였으면, 센터운영자에게 입금 확인을 요청할 수 있습니다.
- [**취소**, **환불 요청 →**](/cancel)

{/* 📸 스크린샷: 입금 확인 요청 버튼이 보이는 신청 상세 화면
- 파일명: my-status-03.png
- 권장 크기: 800x800px (모바일 비율 권장)
- 포함 요소: 신청 상세 정보, "입금 확인 요청" 버튼 (강조 표시)
*/}
