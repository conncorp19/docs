## 내 센터

<Frame caption="내 센터 — 생성 전">
  <img src="/images/manage/create-center-01.png" alt="내 센터 생성 전" />
</Frame>

{/* 📸 스크린샷: 로그인 직후 "내 센터" 화면 (센터가 없는 상태)
    - 파일명: create-center-01.png
    - 권장 크기: 1200x600px
    - 포함 요소: "센터 만들기" 버튼, "새 센터 만들기" 카드
*/}

회원가입 후 로그인하면 **내 센터** 화면이 표시됩니다.
**센터 만들기** 또는 **새 센터 만들기** 카드를 클릭하면 센터 생성을 시작할 수 있습니다.

---

## 요금제 선택

<Frame caption="요금제 선택">
  <img src="/images/manage/create-center-02.png" alt="요금제 선택" />
</Frame>

{/* 📸 스크린샷: 요금제 선택 화면
    - 파일명: create-center-02.png
    - 권장 크기: 1200x700px
    - 포함 요소: Free / Basic / Pro 3개 플랜 카드, 각 플랜의 가격·주요 내용 요약
*/}

새 센터의 요금제를 선택합니다. 각 센터는 독립된 요금제로 운영됩니다.

| 플랜 | 가격 | 주요 내용 |
|------|------|----------|
| **Free** | 무료 | 클래스 10개, 월 신청 20건 |
| **Basic** | ₩9,900/월 | 클래스 30개, 월 신청 50건, SMS 100건/월 |
| **Pro** | ₩29,000/월 | 클래스 50개, 월 신청 200건, 팀원 5명, SMS 300건/월, 활동 로그 |

<Tip>
  먼저 Free 플랜으로 센터를 생성한 후, 필요에 따라 나중에 업그레이드할 수 있습니다.
</Tip>

<Frame caption="센터 이름 입력">

{/* 📸 스크린샷: 센터 이름 입력 화면

## 센터 생성 확인

<Frame caption="센터 생성 확인">
  <img src="/images/manage/create-center-04.png" alt="센터 생성 확인" />
</Frame>

{/* 📸 스크린샷: 센터 생성 최종 확인 화면
    - 파일명: create-center-04.png
    - 권장 크기: 1200x600px
    - 포함 요소: 센터 이름, 선택한 플랜 요약, "센터 생성" 버튼, "프로모션 코드 등록" 링크
*/}

센터 이름과 선택한 플랜을 확인한 후 **센터 생성**을 클릭하면 센터가 만들어집니다.

프로모션 코드가 있다면 하단의 **프로모션 코드 등록**을 클릭하여 입력할 수 있습니다.

## 센터 생성 완료

<Frame caption="센터 생성 완료">
  <img src="/images/manage/create-center-05.png" alt="센터 생성 완료" />
</Frame>

{/* 📸 스크린샷: 센터 생성 완료 화면
    - 파일명: create-center-05.png
    - 권장 크기: 1200x500px
    - 포함 요소: 완료 메시지, "센터로 이동" 버튼, "센터 설정" 버튼
*/}

센터 생성이 완료되면 **센터로 이동** 또는 **센터 설정** 버튼이 표시됩니다.

- **센터 설정** — 입금 계좌, 센터 주소 등 기본 정보를 바로 설정할 수 있습니다.
- **센터로 이동** — 대시보드로 이동합니다.

<Note>
  센터 설정에서 입금 계좌를 먼저 입력하는 것을 권장합니다. 입금 계좌는 수강생에게 안내되는 정보이므로 정확하게 입력해야 합니다.
</Note>

## 내 센터 관리

<Frame caption="내 센터 — 생성 후">
  <img src="/images/manage/create-center-06.png" alt="내 센터 생성 후" />
</Frame>

{/* 📸 스크린샷: 센터가 생성된 후 "내 센터" 화면
    - 파일명: create-center-06.png
    - 권장 크기: 1200x600px
    - 포함 요소: 센터 카드(이름, 플랜, 운영 상태, 공개 여부, 수강생 수, 클래스 수), "관리하기" 버튼, "새 센터 만들기" 카드
*/}

센터가 생성되면 **내 센터** 화면에 센터 카드가 표시됩니다.
센터 이름, 플랜, 운영 상태, 공개 여부, 수강생 수, 클래스 수를 확인할 수 있으며, **관리하기**를 클릭하면 해당 센터의 대시보드로 이동합니다.

추가 센터가 필요한 경우 **새 센터 만들기** 카드를 클릭하여 유료 플랜으로 새 센터를 생성할 수 있습니다.

<Warning>
  Free 플랜 센터는 계정당 1개만 생성할 수 있습니다.
</Warning>
