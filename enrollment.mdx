## 신청 처리 흐름

수강생이 신청하면 아래 흐름에 따라 상태가 변경됩니다.

```
신청 접수
  │
  ├─ 정원 이내 ─→ ┌──────────┐
  │               │ 입금대기  │
  └─ 정원 초과 ─→ ┌──────────┐   정규배정    ┌──────────┐
                  │ 대기신청  │ ───────────→ │ 입금대기  │
                  └──────────┘              └──────────┘
                                                 │
                  ┌──────────────────────────────┘
                  │
                  ├─ 기한 초과 ─→ ┌──────────┐ ─→ 기한연장 / 취소
                  │               │ 기한만료  │
                  │               └──────────┘
                  │
                  │  수강생           ┌────────────┐  입금확인   ┌──────────┐
                  ├─ 입금확인요청 ──→ │입금확인요청 │ ─────────→ │ 입금확인  │
                  │                   └────────────┘  반려       │          │
                  │                        └──────────→ 입금대기 └────┬─────┘
                  │                                                   │
                  │  관리자            ┌──────────┐                   │
                  └─ 입금확인 ───────→ │ 입금확인  │ ─────────────────┤
                                      └──────────┘                   │
                                                          수강확정   │
                                                    ┌────────────────┘
                                                    ▼
                                              ┌──────────┐
                                              │ 수강확정  │
                                              └────┬─────┘
                  ┌─────────────────────────────────┘
                  │
                  │  수강생           ┌──────────┐
                  ├─ 환불요청 ──────→ │ 환불요청  │
                  │                   └────┬─────┘
                  │                        ├─ 전체환불 ──→ ┌──────────┐
                  │                        │               │ 전체환불  │ ─→ 수강유지 가능
                  │                        │               └──────────┘
                  │                        ├─ 부분환불 ──→ ┌──────────┐
                  │                        │               │ 부분환불  │ ─→ 전체환불 / 수강유지
                  │                        │               └──────────┘
                  │                        └─ 환불거절 ──→ 이전 상태
                  │
                  ├─ 관리자 전체환불 ─→ ┌──────────┐ ─→ 수강유지 가능
                  │                     │ 전체환불  │
                  │                     └──────────┘
                  └─ 관리자 부분환불 ─→ ┌──────────┐ ─→ 전체환불 / 수강유지
                                       │ 부분환불  │
                                       └──────────┘
```

<Note>
  기한만료는 DB에 저장되는 상태가 아닙니다. 입금대기 상태에서 입금 기한이 초과되면 화면에 "기한만료"로 표시되며, 자동으로 취소되지 않습니다.
</Note>

## 신청 구조

수강생이 한 번 신청하면 **주문(Order)**이 생성되고, 주문 안에 신청한 클래스 수만큼 **클래스(OrderClass)**가 포함됩니다.

- **주문(Order)** — 수강생의 1회 신청 단위. 여러 클래스를 포함할 수 있습니다.
- **클래스(OrderClass)** — 주문 내 개별 클래스 단위. 각각 독립적인 상태를 가집니다.

주문의 대표 상태는 소속 클래스들 중 우선순위가 가장 높은 상태로 자동 결정됩니다.

## 신청 상태

| 상태 | 설명 |
|------|------|
| <span style={{color: '#6b7280'}}>**대기신청**</span> | 정원 초과로 대기 중입니다. 관리자가 **정규배정**하면 입금대기로 전환됩니다. |
| <span style={{color: '#6b7280'}}>**입금대기**</span> | 수강생의 입금을 기다리고 있습니다. 입금 확인 후 상태를 변경해 주세요. |
| <span style={{color: '#854d0e'}}>**입금확인요청**</span> | 수강생이 "입금했어요" 버튼을 눌러 입금 확인을 요청했습니다. 통장을 확인한 후 **입금확인** 또는 **반려** 처리해 주세요. |
| <span style={{color: '#166534'}}>**입금확인**</span> | 입금이 확인되었습니다. **수강확정** 처리해 주세요. |
| <span style={{color: '#16a34a'}}>**수강확정**</span> | 수강이 확정되었습니다. |
| <span style={{color: '#dc2626'}}>**환불요청**</span> | 수강생이 환불을 요청했습니다. **전체환불**, **부분환불**, **환불거절** 중 선택하여 처리해 주세요. |
| <span style={{color: '#6b7280'}}>**부분환불**</span> | 부분 환불이 완료되었습니다. **수강유지** 또는 **전체환불** 처리가 가능합니다. |
| <span style={{color: '#6b7280'}}>**전체환불**</span> | 전체 환불이 완료되었습니다. 필요한 경우 **수강유지**로 되돌릴 수 있습니다. |
| <span style={{color: '#6b7280'}}>**취소**</span> | 취소된 건입니다. 필요한 경우 **입금대기** 또는 **대기신청**으로 되돌릴 수 있습니다. |
| <span style={{color: '#374151'}}>**기한만료**</span> | 입금대기 상태에서 입금 기한이 초과되면 표시됩니다. 표시 전용 상태이며, **기한연장**, **입금확인**, **취소** 처리가 필요합니다. |

**신청 관리**에서 전체 신청 내역과 수익 현황을 확인할 수 있습니다.
상단의 기간 필터(오늘, 1주일, 1개월, 3개월)로 조회 기간을 변경할 수 있습니다.

상단에 총 수익, 입금액, 환불액이 표시되고, 그 아래에 총 신청수, 수강확정대기, 입금확인요청, 환불요청, 입금대기, 기한만료 건수가 한눈에 보입니다.
각 항목을 클릭하면 해당 상태의 신청 건만 필터링됩니다.

수강생 이름, 연락처, 클래스명으로 검색하거나, 상태별로 필터링하여 원하는 건만 조회할 수 있습니다.

## 주요 처리

### 입금 확인

입금이 확인된 건을 선택하고 **입금확인** 버튼을 클릭하면 입금확인 상태로 변경됩니다.

- **주문 단위 입금확인** — 주문 내 모든 클래스를 한번에 입금확인 처리합니다.
- **클래스 단위 입금확인** — 개별 클래스만 선택하여 입금확인 처리합니다.
- **일괄 입금확인** — 상단의 일괄 입금확인을 클릭하면 여러 주문을 동시에 처리할 수 있습니다.

### 수강 확정

입금확인 상태의 클래스를 **수강확정** 처리합니다.

### 기한 만료 처리

입금 기한이 지난 건은 **기한만료** 상태로 별도 표시됩니다.

- **기한 연장** — 새로운 입금 기한을 설정합니다. 상태는 입금대기로 유지됩니다.
- **입금확인** — 기한이 만료되었더라도 입금확인 처리가 가능합니다.
- **일괄 취소** — 상단의 **입금 기한만료 취소**를 클릭하면 기한만료 건을 일괄 취소할 수 있습니다.

<Note>
  기한이 만료되어도 자동으로 취소되지 않습니다. 사정에 따라 관리자가 유연하게 처리할 수 있습니다.
</Note>

### 환불 처리

수강생이 환불을 요청하거나, 관리자가 직접 환불을 진행할 수 있습니다.

- **전체환불** — 결제 금액 전액을 환불 처리합니다. 입금확인, 수강확정, 환불요청 상태에서 가능합니다.
- **부분환불** — 일부 금액만 환불 처리합니다. 환불 금액을 직접 입력합니다.
- **환불거절** — 수강생의 환불 요청을 거절하고 이전 상태로 되돌립니다.
- **수강유지** — 환불 처리 후에도 수강을 유지할 때 사용합니다. 수강확정 상태로 되돌립니다.

<Warning>
  실제 환불 금액의 이체는 관리자가 직접 처리해야 합니다. 클래스폼은 환불 상태만 관리합니다.
</Warning>

### 대기신청 처리

정원 초과로 대기 중인 수강생을 **정규배정**하면 입금대기 상태로 전환됩니다.
정규배정 시 입금 기한이 자동 설정됩니다.

### 되돌리기

잘못 처리한 건은 이전 상태로 되돌릴 수 있습니다.

- **입금대기로 되돌리기** — 입금확인 또는 취소 상태에서 가능합니다. 입금 기한이 재설정됩니다.
- **입금확인으로 되돌리기** — 수강확정, 전체환불, 부분환불 상태에서 가능합니다.
- **대기신청으로 되돌리기** — 입금대기 또는 취소 상태에서 가능합니다.

신청 건의 **...** 또는 상세 영역을 클릭하면 신청 상세 화면으로 이동합니다.

- **신청 정보** — 신청번호, 신청일, 수강생 이름, 연락처, 상태, 입금 기한, 메모를 확인할 수 있습니다. 연락처 옆의 **SMS** 버튼으로 수강생에게 바로 문자를 보낼 수 있습니다.
- **환불 계좌 정보** — 수강생이 신청 시 입력한 환불 계좌(예금주, 은행, 계좌번호)를 확인할 수 있습니다.
- **신청 클래스** — 신청한 클래스 목록과 각 클래스의 인원현황, 상태, 추가정보, 금액이 표시됩니다. 클래스별로 입금확인, 수강확정, 환불 등의 처리가 가능합니다.
- **결제 정보** — 입금 금액과 총 금액을 확인할 수 있습니다.

## 부가 기능

### 메모

주문 단위와 클래스 단위로 관리자 전용 메모를 남길 수 있습니다. 메모는 수강생에게 보이지 않습니다.

### 신청현황 다운로드

목록 우측 상단의 **신청현황 다운로드**를 클릭하면 현재 조회 중인 신청 내역을 파일로 내려받을 수 있습니다.

### 상태별 날짜 필터

상태 필터를 변경하면 기간 검색의 기준 날짜가 자동으로 변경됩니다. 예를 들어 "수강확정" 필터를 선택하면 수강확정일 기준으로 조회되고, "취소" 필터를 선택하면 취소일 기준으로 조회됩니다.

---

## 권한

- **대표 / 매니저** — 상태 변경, 메모 수정, 조회, SMS 발송, 엑셀 다운로드 모두 가능합니다.
- **스탭** — 조회, SMS 발송, 엑셀 다운로드가 가능합니다. 상태 변경과 메모 수정은 불가합니다.
- **뷰어** — 조회와 엑셀 다운로드만 가능합니다.
