*/}

센터에서 안내받은 주소(`classform.net/center/센터이름`)로 접속하면 클래스 목록을 확인할 수 있습니다.

---

## 클래스 선택 및 장바구니

<Frame caption="클래스 상세">
  ![Ms Apply Class](/images/ms_apply_class.png)
</Frame>

{/* 📸 스크린샷: 장바구니 화면
- 파일명: apply-02.png
- 권장 크기: 800x1000px (모바일 비율 권장)
- 포함 요소: 담긴 클래스 목록, 각 클래스의 수강료, 합계 금액, "신청하기" 버튼
*/}

원하는 클래스의 \[신청하기\]으로 바로 신청하거나,  \[장바구니 담기\]로 여러 클래스를 한번에 담은 후 신청할 수 있습니다.

<Info>
  장바구니는 현재 사용 중인 기기에만 저장됩니다. 다른 기기에서는 장바구니 내용이 보이지 않습니다.
</Info>

---

## 주문서 작성

<Frame caption="주문서 작성">
  ![Ms Apply Reg](/images/ms_apply_reg.png)
</Frame>

{/* 📸 스크린샷: 주문서 작성 화면
- 파일명: apply-03.png
- 권장 크기: 800x1200px (모바일 비율 권장)
- 포함 요소: 신청자 정보(이름, 연락처), 수강생 정보 입력, 요청사항, 개인정보 수집 동의 체크, "신청하기" 버튼
*/}

해당 클래스에 수강을 신청한 적이 있다면 \[로그인\] 후 이용할 수 있습니다. 신규 수강생의 경우 별도 로그인 없이 신청 폼을 작성합니다.

<Tip>
  **신청자와 수강생이 다를 수 있습니다.** 예를 들어 부모님이 자녀를 대신하여 신청하는 경우, 신청자에 부모님 정보를, 수강생에 자녀 정보를 입력하면 됩니다.
</Tip>

## 신청 완료 및 입금 안내

<Frame caption="신청 완료 화면">
  ![Ms Apply Account](/images/ms_apply_account.png)
</Frame>

{/* 📸 스크린샷: 신청 완료 화면
- 파일명: apply-04.png
- 권장 크기: 800x900px (모바일 비율 권장)
- 포함 요소: "신청이 완료되었습니다" 메시지, 입금 계좌 정보(은행/계좌번호/예금주), 입금 금액, 입금 기한
*/}

신청이 완료되면 입금할 계좌와 금액이 안내됩니다. 안내된 계좌로 수강료를 입금하면 센터에서 확인 후 수강이 확정됩니다.

<Note>
  수강료가 무료인 클래스는 신청 즉시 자동으로 입금 확인으로 처리됩니다.
</Note>

## 입금 확인 요청

<Frame caption="신청 완료 화면">
  ![Ms Apply Myorder](/images/ms_apply_myorder.png)
</Frame>

신청 내역에서 신청한 클래스를 확인할 수 있습니다. 입금을 하면 센터운영자에게 \[입금 확인 요청\]을 해주세요. 센터운영자가 보다 빠르게 확인 후 처리할 수 있습니다.
