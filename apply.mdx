## 센터 접속

<Frame caption="센터 페이지">
  ![센터 페이지](/images/student/apply-01.png)
</Frame>

{/* 📸 스크린샷: 수강생이 보는 센터 홈페이지

  - 권장 크기: 800x1200px (모바일 비율 권장)
  - 포함 요소: 센터 로고/이름, 카테고리 탭, 클래스 카드 목록(이미지, 클래스명, 수강료, 정원), "신청하기" 버튼
*/}

센터에서 안내받은 주소(`classform.net/센터이름`)로 접속하면 클래스 목록을 확인할 수 있습니다.

---

## 클래스 선택 및 장바구니

<Frame caption="장바구니">
  ![장바구니](/images/student/apply-02.png)
</Frame>

{/* 📸 스크린샷: 장바구니 화면
  - 파일명: apply-02.png
  - 권장 크기: 800x1000px (모바일 비율 권장)
  - 포함 요소: 담긴 클래스 목록, 각 클래스의 수강료, 합계 금액, "신청하기" 버튼
*/}

원하는 클래스의 **신청하기** 버튼을 클릭하면 장바구니에 담깁니다. 여러 클래스를 한번에 담은 후 함께 신청할 수 있습니다.

<Info>
  장바구니는 현재 사용 중인 기기에만 저장됩니다. 다른 기기에서는 장바구니 내용이 보이지 않습니다.
</Info>

## 주문서 작성

<Frame caption="주문서 작성">
  ![주문서 작성](/images/student/apply-03.png)
</Frame>

{/* 📸 스크린샷: 주문서 작성 화면
  - 파일명: apply-03.png
  - 권장 크기: 800x1200px (모바일 비율 권장)
  - 포함 요소: 신청자 정보(이름, 연락처), 수강생 정보 입력, 요청사항, 개인정보 수집 동의 체크, "신청하기" 버튼
*/}

장바구니에서 **신청하기**를 클릭하면 주문서 작성 화면으로 이동합니다. 신청자 정보(이름, 연락처), 수강생 정보, 요청사항을 입력하고 개인정보 수집에 동의하면 신청이 완료됩니다.

<Tip>
  **신청자와 수강생이 다를 수 있습니다.** 예를 들어 부모님이 자녀를 대신하여 신청하는 경우, 신청자에 부모님 정보를, 수강생에 자녀 정보를 입력하면 됩니다.
</Tip>

## 신청 완료 및 입금 안내

<Frame caption="신청 완료 화면">
  ![신청 완료](/images/student/apply-04.png)
</Frame>

{/* 📸 스크린샷: 신청 완료 화면
  - 파일명: apply-04.png
  - 권장 크기: 800x900px (모바일 비율 권장)
  - 포함 요소: "신청이 완료되었습니다" 메시지, 입금 계좌 정보(은행/계좌번호/예금주), 입금 금액, 입금 기한
*/}

신청이 완료되면 입금할 계좌와 금액이 안내됩니다. 안내된 계좌로 수강료를 입금하면 센터에서 확인 후 수강이 확정됩니다.

<Note>
  수강료가 무료인 클래스는 신청 즉시 자동으로 입금 확인으로 처리됩니다.
</Note>
