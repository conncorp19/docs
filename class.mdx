<Frame caption="클래스 관리 목록">
  ![Mc Class List](/images/mc_class_list.png)
</Frame>

{/* 📸 스크린샷: 클래스 관리 목록 페이지
- 파일명: class-01.png
- 권장 크기: 1200x800px
- 포함 요소: 상단 현황(전체/오픈예정/모집중/대기접수/모집마감, 모집정원/전체신청/수강생/대기신청), 클래스 목록 테이블, 필터/검색, "클래스 만들기" 버튼, "클래스 다운로드" 버튼

**클래스 관리**에서 개설된 클래스 목록을 확인할 수 있습니다. 상단에 공개 클래스의 현황(전체, 오픈 예정, 모집중, 대기 접수, 모집 마감)과 모집 정원, 전체 신청, 수강생, 대기 신청 수가 표시됩니다.

카테고리, 클래스명, 강사명, 상태별로 필터링하여 원하는 클래스만 조회할 수 있습니다. **클래스 다운로드**를 클릭하면 클래스 현황을 파일로 내려받을 수 있습니다.

## 카테고리 설정

<Frame caption="카테고리 설정">
  ![Mc Class Category](/images/mc_class_category.png)
</Frame>

{/* 📸 스크린샷: 카테고리 설정 팝업/화면
- 파일명: class-02.png
- 권장 크기: 1200x600px
- 포함 요소: 카테고리 목록, 공개/비공개 토글, 순서 변경 핸들, 이름 수정 필드
*/}

클래스 관리 우측 상단의 **카테고리 설정**을 클릭하면, 클래스를 분류할 카테고리를 관리할 수 있습니다.

카테고리별로 공개/비공개를 설정할 수 있고, 순서를 변경하거나 이름을 수정할 수 있습니다. 비공개로 설정한 카테고리는 수강신청 페이지에 표시되지 않습니다.

## 클래스 만들기

우측 상단의 **클래스 만들기**를 클릭하면 새로운 클래스를 등록할 수 있습니다.

### (1) 기본 정보

<Frame caption="클래스 기본 정보 입력">
  ![Mc Class C Info](/images/mc_class_c_info.png)
</Frame>

{/* 📸 스크린샷: 클래스 만들기 > 기본 정보 섹션
- 파일명: class-03.png
- 권장 크기: 1200x800px
- 포함 요소: 클래스명 입력, 카테고리 선택, 강사명 선택, 강의 장소 입력, 이미지 업로드 영역, 태그 입력
*/}

클래스명, 카테고리, 강사명, 강의 장소를 입력합니다. 클래스 이미지(권장 1920x1080px, 최대 5MB)와 태그(최대 5개)도 등록할 수 있습니다.

<Info>
  클래스명은 필수 입력 항목입니다.
</Info>

<br />

### (2) 일정

<Frame caption="일정 설정">
  ![Mc Class C Schedule](/images/mc_class_c_schedule.png)
</Frame>

{/* 📸 스크린샷: 클래스 만들기 > 일정 섹션
- 파일명: class-04.png
- 권장 크기: 1200x600px
- 포함 요소: 수강 신청 기간 시작/종료 날짜, 강의 기간 시작/종료 날짜, "상시 모집" 토글, "상시 강의" 토글
*/}

- **수강 신청 기간** — 수강생이 신청할 수 있는 기간을 설정합니다. 시작 일시와 종료 일시를 지정하면 해당 기간에만 신청이 가능합니다.
  - 미설정 시 **상시 신청**으로 노출됩니다.
  - **상시 모집** 토글을 켜면 기간 제한 없이 언제든 신청을 받을 수 있습니다.
- **강의 기간** — 실제 강의가 진행되는 기간을 설정합니다. 시작일과 종료일을 지정합니다.
  - 미설정 시 **상시 강의**로 노출됩니다.
  - **상시 강의** 토글을 켜면 기간 제한 없이 운영할 수 있습니다.
- **강의 시간** — 강의가 진행되는 요일과 시간을 입력합니다.
  - 예를 들어 `월/수 15:00-17:50`과 같이 입력합니다.
  - 최대 5개까지 추가할 수 있어, 요일별로 다른 시간대를 운영하는 경우에도 모두 표기할 수 있습니다.
- **강의 횟수** — 토글을 켜면 총 강의 횟수를 입력할 수 있습니다. 강의 횟수가 정해져 있는 경우 입력하면 수강신청 페이지에 표시됩니다.

<br />

### **(3) 비용 및 인원**

<Frame caption="비용 및 인원 설정">
  ![Mc Class C Quota](/images/mc_class_c_quota.png)
</Frame>

- **수강료** — 수강생이 입금해야 하는 금액입니다. 0원으로 설정하면 무료 클래스로 운영되며, 신청 즉시 자동 확정됩니다.
- **재료비/대여비** — 수강료 외에 별도로 안내할 금액이 있으면 입력합니다. 수강신청 페이지에 표시됩니다.
- **모집인원 (최소)** — 최소 모집 인원입니다.
- **모집인원 (최대)** — 최대 모집 인원입니다. 정원이 차면 자동으로 마감되고, 대기 신청으로 전환됩니다.
- **대기 최대인원** — 정원 초과 시 대기 신청을 받을 최대 인원입니다.

<Tip>
  대기 최대인원을 0으로 설정하면 대기 신청을 받지 않습니다.
</Tip>

<br />

### (4) 상세 정보

<Frame caption="상세 정보 입력">
  ![Mc Class C Desc](/images/mc_class_c_desc.png)
</Frame>

{/* 📸 스크린샷: 클래스 만들기 > 상세 정보 섹션
- 파일명: class-06.png
- 권장 크기: 1200x700px
- 포함 요소: 클래스 소개 리치 텍스트 에디터, 커리큘럼 입력, 취소 및 환불 규정 입력
*/}

클래스 소개, 커리큘럼, 취소 및 환불 규정을 입력할 수 있습니다.

클래스 소개는 서식 편집(볼드, 이탤릭, 목록, 링크, 이미지 삽입 등)이 가능합니다. 취소 및 환불 규정은 클래스별로 개별 설정할 수 있습니다.

<br />

### (5) 수강생 정보 수집

<Frame caption="수강생 정보 수집 설정">
  ![Mc Class C Custom](/images/mc_class_c_custom.png)
</Frame>

{/* 📸 스크린샷: 클래스 만들기 > 수강생 정보 수집 섹션
- 파일명: class-07.png
- 권장 크기: 1200x500px
- 포함 요소: 기본 수집 항목(이름, 연락처), "추가 정보 받기" 영역, 추가 질문 입력 필드
*/}

수강생의 이름과 연락처는 기본으로 수집됩니다. 추가로 받고 싶은 질문이 있으면 **추가 정보 받기**에서 자유롭게 항목을 추가할 수 있습니다.

<br />

### (6) 운영상태

<Frame caption="클래스 운영 상태">
  ![Mc Class C Status](/images/mc_class_c_status.png)
</Frame>

클래스의 공개/비공개 상태를 설정합니다.

수강생에게 표시되는 모집 상태(오픈 예정, 모집중, 대기 접수, 모집 마감)는 수강신청 기간과 정원에 따라 자동 계산됩니다.

<Note>
  클래스를 비공개로 전환하면 수강생 페이지에서 숨겨지며, 플랜 한도에서도 제외됩니다.
</Note>

## 클래스 상세

<Frame caption="클래스 상세 화면">
  ![Mc Class Detail](/images/mc_class_detail.png)
</Frame>

{/* 📸 스크린샷: 클래스 상세 페이지
- 파일명: class-08.png
- 권장 크기: 1200x900px
- 포함 요소: 클래스 정보 요약, 신청/강의 정보, 정원/신청/확정/대기 현황, 수강생 현황 테이블, "SMS 보내기" 버튼, "수강생 다운로드" 버튼
*/}

클래스 목록에서 클래스를 선택하면 상세 화면으로 이동합니다. 클래스 정보, 신청 정보, 강의 정보와 함께 정원, 신청, 확정, 대기 현황을 한눈에 확인할 수 있습니다.

하단의 **수강생 현황**에서 해당 클래스에 신청한 수강생 목록을 확인할 수 있습니다. 이름이나 연락처로 검색하거나, 상태별로 필터링할 수 있습니다.

- **SMS 보내기** — 수강생에게 문자를 발송합니다.
- **수강생 다운로드** — 목록을 파일로 내려받습니다.
- **추가정보 보기** — 각 수강생의 신청 시 입력한 추가 정보를 확인합니다.
- **처리** — 취소 등의 작업을 수행합니다.
