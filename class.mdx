**클래스 관리**에서 개설된 클래스 목록을 확인할 수 있습니다. 상단에 공개 클래스의 현황(전체, 오픈 예정, 모집중, 대기 접수, 모집 마감)과 모집 정원, 전체 신청, 확정 인원, 대기 신청 수가 표시됩니다.

카테고리, 클래스명, 담당자/강사명, 상태별로 필터링하여 원하는 클래스만 조회할 수 있습니다. **클래스 다운로드**를 클릭하면 클래스 현황을 파일로 내려받을 수 있습니다.

카테고리별로 공개/비공개를 설정할 수 있고, 순서를 변경하거나 이름을 수정할 수 있습니다. 비공개로 설정한 카테고리는 신청 페이지에 표시되지 않습니다.

## 클래스 만들기

우측 상단의 **클래스 만들기**를 클릭하면 새로운 클래스를 등록할 수 있습니다.

### (0) 템플릿 선택

클래스를 만들 때 가장 먼저 **템플릿**을 선택합니다. 템플릿에 따라 입력 항목의 라벨과 표시 여부가 자동으로 맞춰져, 수업이 아닌 행사·모임이나 인원 모집에도 자연스럽게 사용할 수 있습니다.

<CardGroup cols={3}>
  <Card title="수업" icon="book">
    정기적으로 진행되는 교육·강좌. 강사, 커리큘럼, 수강료를 관리합니다.

    예시: 성경공부반, 요가 클래스, 원데이 쿠킹
  </Card>

  <Card title="행사·모임" icon="calendar">
    특정 일정에 진행되는 행사·수련회·탐방·모임. 참가자와 참가비를 관리합니다.

    예시: 여름 수련회, 문화센터 체험, 탐방 프로그램
  </Card>

  <Card title="모집" icon="user-plus">
    비용 없이 인원만 모으는 경우. 지원자·신청자로 라벨이 바뀌고 비용 항목은 숨겨집니다.

    예시: 사역팀 지원, 봉사자 모집, 스터디 인원
  </Card>
</CardGroup>

#### 템플릿별 라벨/필드 차이

| 항목 | 수업 | 행사·모임 | 모집 |
| --- | --- | --- | --- |
| 담당 라벨 | 강사 | 담당자 | 담당자 |
| 신청자 라벨 | 수강생 | 참가자 | 신청자 |
| 비용 라벨 | 수강료 | 참가비 | (숨김) |
| 기간 라벨 | 강의 기간 | 행사 기간 | 모집 기간 |
| 커리큘럼 | 표시 | 표시 | 숨김 |
| 강의 시간 | 표시 | 표시 | 숨김 |

<Note>
  템플릿 식별자가 `camp` 에서 `event` 로 변경되었습니다. 기존에 캠프 템플릿으로 만든 클래스는 자동으로 행사·모임으로 표시됩니다.
</Note>

<Tip>
  동적 라벨에는 한글 조사("이/가", "을/를")가 받침 유무에 맞춰 자동으로 적용됩니다. 예: "수강생이" / "참가자가".
</Tip>

<br />

### (1) 기본 정보

<Frame caption="클래스 기본 정보 입력">
  ![Mc Class C Info](/images/mc_class_c_info.png)
</Frame>

{/* 📸 스크린샷: 클래스 만들기 > 기본 정보 섹션
- 파일명: class-03.png
- 권장 크기: 1200x800px
- 포함 요소: 클래스명 입력, 카테고리 선택, 강사명 선택, 강의 장소 입력, 이미지 업로드 영역, 태그 입력
*/}

클래스명, 카테고리, 담당자/강사명, 장소를 입력합니다. 클래스 이미지(권장 1920x1080px, 최대 5MB)와 태그(최대 5개)도 등록할 수 있습니다.

<Note>
  템플릿이 **행사·모임** 또는 **모집** 인 경우 "강사" 라벨은 "담당자"로 자동 표시됩니다.
</Note>

<Info>
  클래스명은 필수 입력 항목입니다.
</Info>

<br />

### (2) 일정

<Frame caption="일정 설정">
  ![Mc Class C Schedule](/images/mc_class_c_schedule.png)
</Frame>

{/* 📸 스크린샷: 클래스 만들기 > 일정 섹션
- 파일명: class-04.png
- 권장 크기: 1200x600px
- 포함 요소: 수강 신청 기간 시작/종료 날짜, 강의 기간 시작/종료 날짜, "상시 모집" 토글, "상시 강의" 토글
*/}

- **신청 기간** — 신청자가 신청할 수 있는 기간을 설정합니다. 시작 일시와 종료 일시를 지정하면 해당 기간에만 신청이 가능합니다.
  - 미설정 시 **상시 신청**으로 노출됩니다.
  - **상시 모집** 토글을 켜면 기간 제한 없이 언제든 신청을 받을 수 있습니다.
- **진행 기간** — 실제 강의·행사가 진행되는 기간을 설정합니다. 템플릿에 따라 라벨이 **강의 기간/행사 기간/모집 기간** 으로 자동 표시됩니다.
  - 미설정 시 **상시 진행**으로 노출됩니다.
  - **상시 진행** 토글을 켜면 기간 제한 없이 운영할 수 있습니다.
- **진행 시간** — 진행되는 요일과 시간을 입력합니다.
  - 예를 들어 `월/수 15:00-17:50`과 같이 입력합니다.
  - 최대 5개까지 추가할 수 있어, 요일별로 다른 시간대를 운영하는 경우에도 모두 표기할 수 있습니다.
- **진행 횟수** — 토글을 켜면 총 진행 횟수를 입력할 수 있습니다. 횟수가 정해져 있는 경우 입력하면 신청 페이지에 표시됩니다.

<Note>
  **모집** 템플릿에서는 진행 시간·횟수 항목이 자동으로 숨겨집니다.
</Note>

<br />

### **(3) 비용 및 인원**

<Frame caption="비용 및 인원 설정">
  ![Mc Class C Quota](/images/mc_class_c_quota.png)
</Frame>

- **비용** — 신청자가 입금해야 하는 금액입니다. 템플릿에 따라 라벨이 **수강료/참가비** 로 자동 표시됩니다. 0원으로 설정하면 무료 클래스로 운영되며, 신청 즉시 자동 확정됩니다.
- **금액 표시** — 클래스별로 가격 영역을 신청 페이지에 보일지 끌지 설정합니다. 무료 프로그램이거나 가격을 비공개로 운영하는 경우(교회·비영리 등) 금액 영역을 숨길 수 있습니다.
- **재료비/대여비** — 비용 외에 별도로 안내할 금액이 있으면 입력합니다. 신청 페이지에 표시됩니다.
- **모집인원 (최소)** — 최소 모집 인원입니다.
- **모집인원 (최대)** — 최대 모집 인원입니다. 정원이 차면 자동으로 마감되고, 대기 신청으로 전환됩니다.
- **대기 최대인원** — 정원 초과 시 대기 신청을 받을 최대 인원입니다.

<Tip>
  대기 최대인원을 0으로 설정하면 대기 신청을 받지 않습니다.
</Tip>

<Note>
  템플릿이 **모집** 인 경우 비용 항목 자체가 입력 폼에서 숨겨집니다.
</Note>

### (6) 운영상태

<Frame caption="클래스 운영 상태">
  ![Mc Class C Status](/images/mc_class_c_status.png)

클래스의 공개/비공개 상태를 설정합니다.

<Note>

## 클래스 상세

<Frame caption="클래스 상세 화면">
  ![Mc Class Detail](/images/mc_class_detail.png)
</Frame>

{/* 📸 스크린샷: 클래스 상세 페이지
- 파일명: class-08.png
- 권장 크기: 1200x900px
- 포함 요소: 클래스 정보 요약, 신청/강의 정보, 정원/신청/확정/대기 현황, 수강생 현황 테이블, "SMS 보내기" 버튼, "수강생 다운로드" 버튼
*/}

클래스 목록에서 클래스를 선택하면 상세 화면으로 이동합니다. 클래스 정보, 신청 정보, 진행 정보와 함께 정원, 신청, 확정, 대기 현황을 한눈에 확인할 수 있습니다.

하단의 **신청자 현황**에서 해당 클래스에 신청한 신청자 목록을 확인할 수 있습니다. 이름이나 연락처로 검색하거나, 상태별로 필터링할 수 있습니다.

- **SMS 보내기** — 신청자에게 문자를 발송합니다.
- **신청자 다운로드** — 목록을 파일로 내려받습니다.
- **추가정보 보기** — 각 신청자의 신청 시 입력한 추가 정보를 확인합니다.
- **처리** — 취소 등의 작업을 수행합니다.
