## 서비스 전반

<AccordionGroup>
  <Accordion title="클래스폼은 어떤 서비스인가요?">
    클래스 모집 페이지를 만들고, 수강신청 접수부터 수강료 관리까지 한 곳에서 할 수 있는 클래스 모집/관리 플랫폼이에요.
  </Accordion>

  <Accordion title="무료로도 충분히 사용할 수 있나요?">
    네, Free 플랜은 영구 무료예요. 소규모 스터디나 일회성 행사에 충분해요. 더 많은 클래스나 신청이 필요하면 유료 플랜으로 업그레이드하세요.
  </Accordion>

  <Accordion title="구글 폼 대신 클래스폼을 쓰면 뭐가 좋은가요?">
    구글 폼으로는 정원 관리, 입금 확인, 대기자 관리를 할 수 없어요. 클래스폼은 수강신청 접수, 입금 관리, 정원과 대기자 관리, SMS 알림까지 한 곳에서 처리돼요.
  </Accordion>

  <Accordion title="사업자등록증이 없어도 되나요?">
    네. 클래스폼은 수강료를 중개하지 않아요. 사업자 여부와 관계없이 누구나 센터를 만들 수 있어요.
  </Accordion>

  <Accordion title="센터를 여러 개 만들 수 있나요?">
    네. 하나의 계정으로 여러 센터를 생성하고 운영할 수 있어요. 각 센터는 독립된 요금제로 운영돼요. Free 플랜 센터는 계정당 1개만 생성할 수 있어요.
  </Accordion>

  <Accordion title="수강생의 개인정보는 안전한가요?">
    모든 데이터는 암호화된 연결(HTTPS)으로 전송돼요. PIN은 해시 처리되어 저장되며 원본 복원이 불가능해요. 데이터는 매일 자동 백업돼요.
  </Accordion>
</AccordionGroup>

## 수강료와 요금

<AccordionGroup>
  <Accordion title="수강료가 클래스폼을 거쳐 가나요?">
    아니요. 수강료는 센터 계좌로 직접 입금돼요. 클래스폼은 수강신청 상태와 입금 상태만 관리해요. PG 수수료, 건당 수수료는 없어요.
  </Accordion>

  <Accordion title="월 사용료 이외에 추가 비용이 있나요?">
    없어요. 플랜 요금 외에 추가로 부과되는 수수료는 없어요. 수강료는 센터 계좌로 직접 입금되기 때문에 PG 수수료도 발생하지 않아요.
  </Accordion>

  <Accordion title="온라인 카드결제(PG)를 지원하나요?">
    현재는 계좌이체 기반 수강료 관리에 집중하고 있어요. PG 연동은 향후 추가 예정이에요.
  </Accordion>

  <Accordion title="유료 플랜은 어떻게 결제하나요?">
    센터 관리 화면의 **결제/사용량** 메뉴에서 원하는 플랜으로 변경할 수 있어요. 결제를 진행하면 바로 업그레이드돼요.
  </Accordion>
</AccordionGroup>

## 클래스 운영

<AccordionGroup>
  <Accordion title="입금 확인은 자동으로 되나요?">
    아니요, 입금 확인은 운영자가 직접 해요. 통장 확인 후 클릭 한 번이면 상태 반영과 수강생 안내까지 끝나요.
  </Accordion>

  <Accordion title="수강생이 입금 기한을 넘겼는데 자동으로 취소되나요?">
    자동 취소되지 않아요. 기한이 지나면 **기한만료** 상태로 표시되며, 관리자가 직접 확인 후 취소하거나 입금을 승인할 수 있어요. 소규모 센터에서 사정을 고려하여 유연하게 운영할 수 있도록 설계했어요.
  </Accordion>

  <Accordion title="클래스 정원이 다 차면 어떻게 되나요?">
    정원이 찬 클래스는 **대기 신청**으로 전환돼요. 빈자리가 생기면 대기자를 정규로 배정할 수 있어요.
  </Accordion>

  <Accordion title="한 수강생이 같은 클래스를 두 번 신청할 수 있나요?">
    같은 수강생(연락처\+이름 기준)이 동일한 클래스에 중복 신청하면 안내 메시지가 표시되며 신청이 불가해요. 다만 신청자와 수강생이 다른 경우(예: 부모가 자녀를 대신 신청)는 허용돼요.
  </Accordion>

  <Accordion title="입금액이 수강료와 다르면 어떻게 되나요?">
    관리자는 반려 처리를 할 수 있어요. 반려 처리 시 수강생에게 메시지를 보내 안내할 수 있어요. 관리자가 상황을 확인한 후 최종 결제 금액을 직접 수정할 수 있어요.
  </Accordion>

  <Accordion title="환불은 어떻게 처리하나요?">
    수강생이 환불을 요청하면 운영자에게 **환불요청** 상태로 표시돼요. 운영자가 전체환불/부분환불/거절을 선택해요. 실제 환불 금액의 이체는 운영자가 직접 처리해요.
  </Accordion>

  <Accordion title="수강료가 무료인 프로그램도 운영할 수 있나요?">
    네. 수강료를 0원으로 설정하면 신청 즉시 입금 확인으로 처리돼요.
  </Accordion>

  <Accordion title="교회 수련회나 성경공부 접수에도 사용할 수 있나요?">
    네. 부모님이 자녀를 대신 신청할 수도 있어요. 커스텀 질문으로 필요한 정보도 수집할 수 있어요.
  </Accordion>
</AccordionGroup>

## 센터 관리

<AccordionGroup>
  <Accordion title="여러 운영진이 함께 관리할 수 있나요?">
    네, 하나의 센터에 여러 관리자가 접속하여 함께 신청 관리, 입금 확인 등의 업무를 처리할 수 있어요. 팀원 관리는 Pro 플랜 이상에서 사용할 수 있어요.
  </Accordion>

  <Accordion title="수강신청 페이지 주소를 나중에 바꿀 수 있나요?">
    센터 URL 주소는 최초 등록 시에만 설정할 수 있으며, 이후 변경할 수 없어요. 처음 등록할 때 신중하게 정해 주세요.
  </Accordion>

  <Accordion title="수강생 데이터를 엑셀로 받을 수 있나요?">
    네. 클래스 목록, 수강생 목록, 신청 목록을 파일로 다운로드할 수 있어요.
  </Accordion>

  <Accordion title="SMS 포함 수량을 초과하면 어떻게 되나요?">
    포함 수량을 초과하면 해당 빌링 주기가 끝날 때까지 SMS 발송이 중단돼요. 다음 빌링 주기에 자동으로 리셋돼요. 별도의 충전은 제공하지 않아요.
  </Accordion>
</AccordionGroup>

## 계정·센터 삭제

<AccordionGroup>
  <Accordion title="센터를 삭제하려는데 삭제가 안 돼요.">
    최근 30일 이내에 미처리 신청(입금대기, 입금확인요청, 입금확인, 환불요청)이 있으면 센터를 삭제할 수 없어요. 미처리 신청을 모두 처리(확정, 취소, 환불 등)한 후 다시 시도해 주세요.
  </Accordion>

  <Accordion title="회원 탈퇴를 하면 센터는 어떻게 되나요?">
    소유하고 있는 센터가 있으면 탈퇴할 수 없어요. 먼저 소유한 센터를 모두 삭제한 후 탈퇴를 진행해 주세요. 다른 센터에 팀원으로 참여하고 있는 경우에는 탈퇴 시 자동으로 해당 센터에서 제외돼요.
  </Accordion>

  <Accordion title="센터를 삭제하면 데이터가 복구되나요?">
    아니요. 센터 삭제 시 클래스, 수강생, 신청 데이터가 모두 삭제되며 복구할 수 없어요. 삭제 전에 필요한 데이터는 다운로드 기능을 활용하여 백업해 두세요.
  </Accordion>
</AccordionGroup>
